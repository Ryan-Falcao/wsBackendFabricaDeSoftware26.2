01 — SOBRE

Uma API feita para jogar com dados.

O projeto permite que usuários criem suas contas, pesquisem jogos, encontrem ofertas e mantenham sua própria biblioteca pessoal.

🔐

Autenticação JWT

Sistema de autenticação baseado em Access Token e Refresh Token para proteger as operações da biblioteca.

🎮

Biblioteca pessoal

Adicione jogos, consulte sua biblioteca, altere suas notas e remova títulos.

💰

Ofertas em tempo real

Integração com a CheapShark API para pesquisa de jogos e consulta de ofertas.

📚

OpenAPI

Documentação completa dos endpoints através do Swagger UI e ReDoc.

03 — ENDPOINTS

Uma API simples de consumir.

Os principais recursos disponíveis na API.

GET /api/status/ Verifica se a API está online
GET /api/jogos/buscar/ Pesquisa jogos
GET /api/jogos/buscar/ofertas/ Pesquisa e filtra ofertas
POST /api/usuario/cadastrar/ Cria um usuário
POST /api/usuario/login/ Realiza autenticação
POST /api/biblioteca/adicionar/jogo 🔒 Adiciona jogo
GET /api/biblioteca/me 🔒 Lista biblioteca
PUT /api/biblioteca/alterar/nota 🔒 Altera nota
DELETE /api/biblioteca/jogo/{id}/ 🔒 Remove jogo
